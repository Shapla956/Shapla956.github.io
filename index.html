An outbreak, and the day it changes

A small experiment you can run.

An outbreak grows at a rate set by how fast the infection spreads. When something changes, such as a public health measure, that rate shifts. This chart simulates one outbreak whose transmission rate changes on a single day. Move the sliders and see whether the change shows up in the data, and how well a simple estimate recovers it.

Recovery rate fixed at 0.20 per day. Vertical axis is logarithmic.

A simplified stochastic model for illustration. It is separate from my capstone, which tackles the harder version of this problem: finding such shifts in the evolutionary trees of virus genomes, using deep learning trained on simulated data.
